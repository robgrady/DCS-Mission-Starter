Repository: https://github.com/robgrady/DCS-Mission-Starter

This is a complete, tested Python application (FastAPI). Setup is:

1. Import the repo (Import from GitHub). Keep every file unchanged, including
   the vendor/ directory and frontend/index.html.
2. Install dependencies: pip install -r requirements.txt
3. Run: uvicorn server.app:app --host 0.0.0.0 --port $PORT
   (the included .replit file already configures Run and Deployment; use it.)
4. Deploy with Autoscale. The app is stateless — no database, no persistent
   disk, nothing else to configure.

Do NOT:
- Rebuild or restyle the frontend. Serve frontend/index.html exactly as shipped.
- Add, remove, or rename any API endpoints or UI screens.
- Modify anything in vendor/ (LGPL-licensed third-party library, must stay intact).
- Add a database, ORM, or auth. None are needed.

Verify success:
- GET /api/health returns 200 with "ok": true.

  and the header version matches the top entry in CHANGELOG.md (v1.19.1).
